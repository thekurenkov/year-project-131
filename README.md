## 📌 Итоговая тема

**№131. Прогнозирование оттока клиентов (Churn Prediction)**

**Проблема.** Компания теряет клиентов, но не знает заранее, кто уйдёт. Из-за этого деньги на удержание тратятся неэффективно.

**Цель.** Построить модель, которая по историческим данным о клиенте предсказывает вероятность его оттока в ближайший период.

| Параметр | Значение |
|---|---|
| Тип задачи | Бинарная классификация |
| Данные | Telco Customer Churn (Kaggle), IBM sample datasets, датасеты подписочных сервисов на Kaggle |
| Методы | Logistic Regression (baseline), Random Forest, Gradient Boosting (XGBoost / LightGBM / CatBoost) |
| Метрики | ROC-AUC, F1, Precision/Recall (с учётом дисбаланса классов), бизнес-метрика (стоимость FN/FP) |
| Усложнения | SHAP/LIME, cost-sensitive learning, uplift-модели для оценки retention-кампании |

### ✅ Критерии приёмки
- [ ] Модель обучена и провалидирована на отложенной выборке
- [ ] ROC-AUC не ниже согласованного порога и выше naive baseline
- [ ] Топ-N клиентов по вероятности оттока проверены на разумность (интерпретация признаков)
- [ ] Подготовлен отчёт с бизнес-рекомендациями по удержанию
